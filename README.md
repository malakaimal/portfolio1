# Aimal Khan | Personal Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — premium navy, gold and white design
- `script.js` — mobile navigation, back-to-top button and current year

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, or open the folder in VS Code.
3. To publish it, upload the three website files to your hosting provider's public web directory.

## Personalisation
- The profile uses an `AK` monogram as requested. No personal photograph is required.
- The contact email currently shown is the ILM project email. Replace it if you want a personal email displayed.
- Project descriptions intentionally distinguish ideas and work in progress from completed products.
- Update the HTML whenever your education, skills or project status changes.

This is a static portfolio. It does not include a login system, database, contact form backend or admin dashboard.
